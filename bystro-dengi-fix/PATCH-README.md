# Исправление ошибки сборки на Vercel

## Причина
Сборка падала, потому что код создавал подключение к базе данных
на этапе сборки, а не во время работы сайта. На Vercel в момент сборки
переменной DATABASE_URL может не быть — и сборка падала.

## Что исправлено (4 файла)
1. src/db/index.ts              — подключение к БД создаётся лениво
2. src/app/layout.tsx           — рендеринг динамический, сборка не ходит в БД
3. src/lib/merchant.ts          — добавлен getMerchantSafe()
4. src/components/SiteFooter.tsx — использует безопасную версию

## Как применить
Распакуйте архив поверх папки проекта с заменой файлов, затем:

    git add -A
    git commit -m "Fix: сборка не требует базу данных"
    git push

## ВАЖНО: удалите этот архив после применения
Файл public/bystro-dengi-fix.zip доступен по адресу сайта.
После успешного деплоя удалите его и снова сделайте commit + push.
